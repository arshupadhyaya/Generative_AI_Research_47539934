# Generative AI Research Project

This repository contains organised research materials for the project **"Using Generative AI Tools – Boon or Bane"**.

## Repository Structure

- `01_Literature_Review/`: Contains journal articles, conference papers, books, and news articles used for the literature review.
- `02_Quantitative_Analysis/`: Contains survey questions, raw and cleaned survey data, Python scripts, CSV/Excel files, and quantitative analysis reports.
- `03_Qualitative_Analysis/`: Contains interview transcripts, interview protocols, consent forms, coding documents, insights reports, and qualitative visualisations.
- `04_Drafts_and_Reports/`: Contains draft research proposals, conference papers, and final research reports.
- `05_Additional_Materials/`: Contains information sheets, photos, and other media files.

## Naming Convention

Currently all file use placeholder names like interview1.txt, but when the project starts appropriate naming conventions should be discussed and be consistent throughout the project.

This helps team members identify the file contents, date, and version without needing to open the file.

## Collaboration Guidelines

1. Pull the latest version of the repository before making changes.
2. Create a new branch before editing files.
3. Use clear commit messages that describe the changes made.
4. Submit a pull request for review before merging changes into the main branch.


## Sensitive Data

Files such as consent forms, interview transcripts, and raw participant data should be treated as confidential and only shared with authorised team members. The github project leader should assign these authorisation levels.
